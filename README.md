# 基于 SpringBoot + Vue 的中药店管理系统

药材销售 · 电子处方 · 库存预警 · 采购物流 · 在线支付 · 病症处方 · 数据统计 · 三端协同

本项目是一套面向中药店场景的数字化管理平台，采用前后端分离架构，覆盖**管理员、用户（顾客）、医生（药师）**三类角色。系统围绕"药材管理、电子处方、库存预警、采购物流、订单管理、在线支付、销售统计、病症处方、供应商管理、员工管理、公告管理、用户管理"等核心业务设计，支持从顾客浏览药材、在线下单、支付购药，到医生开具病症处方、审核处方、管理库存，再到管理员全平台监管、药材采购、供应商管理、数据统计的全链路数字化运营，同时融入电子处方与病症关联特色功能，构建中药店"医+药+销"一体化的综合管理平台。

## 核心特性

- **三角色权限体系**：区分管理员、用户（顾客）、医生（药师），基于 RBAC 模型实现功能权限与数据权限控制，顾客在线购药，医生开方审方，管理员负责平台监管与运维。
- **电子处方与病症关联**：医生可在线开具电子处方，关联病症信息（如感冒、脾胃虚弱、气血不足等），支持处方审核、处方查询、处方追溯，处方与订单联动，顾客凭处方购药，符合中药店"先诊后药"的业务逻辑。
- **库存预警与批次管理**：设置库存上下限阈值，当药材库存低于预警值时自动提醒补货；支持药材批次管理（生产日期、有效期），近效期药材优先出库，保障药材质量。
- **采购物流全流程**：覆盖"采购申请→供应商下单→物流跟踪→验收入库→库存更新"全流程，采购物流信息全程可追溯，支持采购订单状态跟踪与到货提醒。
- **完整购药闭环**：覆盖"浏览药材→加入购物车→提交订单→在线支付→医生审方→配药发货→确认收货→评价晒单"全流程，订单状态机涵盖待支付、待审方、已审方、配药中、已发货、已完成、已取消、已退款等状态。
- **销售统计与数据看板**：管理员与医生端提供多维度数据统计，包括销售额趋势、热门药材排行、处方量统计、库存周转率、供应商供货分析等，支持图表可视化展示。
- **供应商管理**：管理药材供应商信息，包括供应商名称、联系人、地址、合作药材、供货价格、供货时效、信誉评分，支持供应商评估与采购决策参考。
- **在线支付与订单跟踪**：集成在线支付功能，支持微信支付、支付宝支付等多种方式；用户可实时查看订单状态、物流信息与处方详情。

## 功能模块概览

## 管理员端

管理员为平台核心运营角色，负责全平台监管与运维：

### 账号与基础

- **管理员管理**：管理管理员账号，包括账号增删改查、角色分配、权限配置、登录日志查看，支持修改密码与安全设置。
- **用户管理**：管理注册用户（顾客）信息，包括昵称、头像、手机号、地址簿、账户状态，支持账号冻结/解冻、违规用户处理。
- **员工管理**：管理药店员工与医生信息，包括姓名、工号、岗位（药师/库管/收银等）、联系方式、入职时间、账户状态，支持员工账号开通与权限分配。
- **药店管理**：管理药店基本信息，包括药店名称、地址、联系电话、营业时间、药店公告、营业执照信息，支持多门店管理（如为连锁药店）。

### 药材与库存

- **药材管理**：管理全平台药材信息，包括药材名称、分类（中药材/中成药/中药饮片）、规格、产地、功效、价格、图片、描述、上架状态，支持药材增删改查与批量操作。
- **药店库存**：查看各门店/仓库的药材库存情况，支持库存查询、库存调整、库存盘点，实时掌握库存动态。
- **库存统计**：统计全平台库存数据，包括库存总量、库存金额、库存周转率、低库存药材排行、近效期药材预警，支持报表导出。
- **库房预警**：设置库存上下限阈值，当药材库存低于下限或高于上限时自动触发预警通知，支持预警规则配置与预警记录查询。

### 采购与供应商

- **供应商管理**：管理药材供应商信息，包括供应商名称、联系人、电话、地址、合作药材、供货价格、信誉评分、合作状态，支持供应商增删改查与评估。
- **药材采购**：创建与管理采购订单，包括选择供应商、选择药材、填写采购数量与价格、提交采购申请，支持采购订单审批流程与采购记录查询。
- **采购物流**：跟踪采购订单的物流状态，包括发货时间、物流公司、物流单号、预计到货时间、实际到货时间，支持物流信息录入与查询。

### 订单与处方

- **订单信息**：查看平台全部销售订单，包括订单号、顾客信息、药材明细、订单金额、订单状态、处方关联信息，支持订单筛选、退款处理、纠纷仲裁。
- **订单详情**：查看订单详细信息，包括收货地址、支付方式、支付时间、发货时间、物流信息、处方详情、操作日志。
- **订单评价**：查看全平台订单评价，包括评分、评价内容、关联订单，支持评价审核（隐藏违规评价）、差评标记与处理。
- **电子处方**：管理全平台电子处方，包括处方号、开方医生、关联顾客、病症信息、药材明细、处方状态（待审核/已审核/已驳回），支持处方查询与处方追溯。
- **病症处方**：管理病症与处方的关联数据，支持按病症分类统计处方量、分析常见病症用药规律，为药材采购与销售策略提供参考。

### 内容与数据

- **公告管理**：发布与管理平台公告，包括公告标题、内容、类型（通知/活动/健康科普）、发布时间、置顶状态，支持公告编辑与删除。
- **缴费记录**：查看平台全部缴费记录，包括订单支付、处方缴费、退款记录，支持按时间、支付方式、金额筛选，支持财务报表导出。
- **物流信息**：管理销售订单的物流信息，包括物流公司、物流单号、发货状态、物流轨迹，支持物流信息录入与查询。
- **销售统计**：综合销售数据看板，展示核心经营指标（今日销售额/订单量/新增用户/处方量），支持销售趋势分析、热门药材排行、顾客购买偏好分析、品类销售占比等多维度图表展示，支持报表导出。
- **数据统计**：综合数据看板，整合销售、库存、采购、处方等多维度数据，提供全局运营视图，支持自定义报表与数据导出。

## 用户端（顾客）

用户为平台的服务需求方，可在线浏览药材、下单购药：

### 账号与个人

- **账户注册登录**：支持手机号+验证码注册登录、账号密码登录，支持找回密码，首次登录自动创建用户档案。
- **密码修改**：支持用户自主修改登录密码，保障账户安全。
- **个人信息**：查看与编辑个人基本信息，包括昵称、头像、手机号、收货地址簿（支持多地址管理），支持查看个人订单历史与评价记录。

### 购药与订单

- **药材购买**：浏览平台药材列表，支持按分类（中药材/中成药/中药饮片）、功效、价格、产地筛选，查看药材详情（图片、名称、分类、规格、产地、功效、价格、库存、用法用量），支持搜索药材、加入购物车、提交订单。
- **我的订单**：查看本人全部购药订单，包括订单号、药材明细、订单金额、订单状态（待付款/待审方/已审方/配药中/已发货/已完成/已取消），支持订单筛选、取消待付款订单、确认收货、申请退款。
- **在线支付**：对待付款订单进行在线支付，支持微信支付、支付宝支付等多种方式，支付成功后自动更新订单状态并通知药店。
- **缴费记录**：查看个人全部缴费记录，包括支付金额、支付方式、支付时间、关联订单，支持缴费记录查询与下载。

### 评价与互动

- **订单评价**：对已完成订单进行评价，包括药材评分、服务评分、评价内容，支持查看历史评价记录。

## 医生端（药师）

医生为平台的专业服务提供方，专注处方开具与店内运营：

### 账号与个人

- **账户注册登录**：支持医生账号注册登录，注册时需提交执业资质与认证材料，审核通过后开通处方权限，支持修改密码与安全设置。
- **密码修改**：支持医生自主修改登录密码，保障账户安全。
- **店内库存**：查看药店当前药材库存情况，包括药材名称、规格、当前库存、预警状态，方便开方时参考库存 availability。

### 处方与订单

- **病症处方**：在线开具电子处方，包括选择顾客、填写病症诊断、选择药材、设置用量用法、添加医嘱备注，提交后处方进入审核流程；支持处方查询、处方编辑（未审核前）、处方驳回处理。
- **订单管理**：查看与处方关联的销售订单，包括订单号、顾客信息、处方详情、药材明细、订单状态，支持订单审方（审核/驳回）、配药确认、发货操作。
- **订单物流**：查看已发货订单的物流状态，包括物流单号、物流公司、物流轨迹，方便解答顾客物流咨询。
- **订单评价**：查看本人关联订单的顾客评价，包括评分、评价内容，支持查看历史评价记录与评价统计。

### 库存与数据

- **库存统计**：查看药店库存统计数据，包括库存总量、低库存药材、近效期药材、库存周转率，支持库存报表查看。
- **员工管理**：管理药店员工信息（如为店长/主管角色），包括员工姓名、岗位、联系方式、工作状态，支持员工排班与权限分配。
